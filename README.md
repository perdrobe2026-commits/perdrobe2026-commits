# PerDrobe


TED University · Computer Engineering  
CMPE 491–492 · 2026–2027


We are a three-student capstone team working on personalized clothing recommendations. Our planned system will use wardrobe context, style preferences and interaction signals to support outfit and shopping recommendations. The project is currently at the proposal stage.
